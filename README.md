# Side Quest — NYC Campus Map

A branded, responsive map of colleges and universities across New York City's five boroughs.

## Run locally
Open this folder in VS Code with Live Server, or run `python3 -m http.server 5500` and visit http://localhost:5500. Internet connection required for map tiles and campus boundary data.

## Files
- `index.html` — map and interface
- `colleges.js` — college dataset
- `LOGO.png` — Side Quest logo
- `build.py` — generates the bundled `campus-map.html`

The project uses MapLibre GL JS and OpenFreeMap tiles. Verify institution data before publishing.
